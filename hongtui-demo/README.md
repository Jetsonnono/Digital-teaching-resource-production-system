# 虹蜕 · 飞虹塔色谱兽（动态演示）

可拖色谱滑条的 one-shot 原型：釉眠 → 虹行 → 窑醒。

## Run

```bash
cd hongtui-demo
npm install
npm run dev
```

Open the printed local URL (default `http://127.0.0.1:5177`).

## Controls

- Drag the chroma slider: glaze bands, beast silhouette, and pagoda layers morph together.
- Release to snap-lock one of three states: **釉眠** / **虹行** / **窑醒**.
- Spectrum stops: 窑青 → 孔雀绿 → 胭脂焰 → 蜜琥珀 → 霜白釉.
